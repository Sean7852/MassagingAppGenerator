# Decisions — spec version 1

Each decision says who made it. "Human" is the human author; "AI default" means the AI proposed
it and the human accepted it.

| # | Decision | Why | By |
|---|---|---|---|
| D1 | Transport is WebSocket with one JSON object per text frame. | Server can push; no polling. | Human (stack choice) |
| D2 | Messages are identified by (sender, client-generated lowercase UUID v4). The server dedups on it. | Makes resending safe, which the offline outbox in v2 relies on. | AI default, accepted |
| D3 | Names match `^[a-z0-9_]{1,32}$`, checked only by the server. | One authority, so clients cannot disagree. | AI default, accepted 2026-10-11 |
| D4 | On a second login with the same name, the newest connection wins. | A client that dropped without a clean close can log in again at once. | AI default, accepted 2026-10-11 |
| D5 | Messages to a name that has never logged in are accepted and held. | Users exist by name only; there is no registration. | AI default, accepted 2026-10-11 |
| D6 | Clients send their queue one message at a time (one in flight). | Smallest state machine to specify and to generate identically in two languages; order is automatic. | Human, on AI recommendation, 2026-10-11 |
| D7 | The client prints a fixed, line-based format on stdout and nothing else. Text values are escaped and come last. | Output can be compared byte for byte across clients. | AI default, pending confirmation |
| D8 | Client-raised errors have fixed codes and fixed messages. | Two clients print identical lines, not just identical codes. | AI default, pending confirmation |
| D9 | In v1 the name is typed with `/login` on every launch; remembering it between launches comes with the v2 local storage. | Keeps v1 free of disk state; v2 adds the data folder for the outbox anyway. | AI default, pending confirmation |
| D10 | In v1 a lost connection reports each unsent message as `ERROR code=not_sent` and the client does not reconnect. | v1 is online only; losses are visible instead of silent. v2 replaces this with the outbox. | AI default, pending confirmation |
| D11 | Platform specs pin the libraries (`websockets` 15 for Python; `ws` 8 and TypeScript 5.9 for Node) and the risky pieces of I/O (stdin on Windows, UTF-8, flushing, exiting). | These are where generated code most often breaks or differs between runs. | AI default, pending confirmation |
